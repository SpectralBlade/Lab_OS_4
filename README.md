# Лабораторная работа № 4, вариант 6

`parent.exe` открывает файл с целыми числами и запускает `child.exe`. Дочерний
процесс считает сумму каждой непустой строки и передаёт её родителю через
отображаемую память. Передачу согласуют два события Windows.

## Сборка и запуск

В CLion соберите и запустите цель `parent`. CMake сначала соберёт `child` и
скопирует входные файлы в `cmake-build-debug`. На запрос `Input file:` введите
`input.txt` при рабочей папке `cmake-build-debug`. Для примера программа
выводит `6`, `6`, `7`.

Для проверок вводите имя файла из таблицы. Все пути указаны относительно
`cmake-build-debug`.

| Вводимое имя | Ожидаемый результат | Код выхода |
| --- | --- | ---: |
| `tests/last_line_no_newline.txt` | `5` | 0 |
| `tests/5000_ones.txt` | `5000` | 0 |
| `tests/long_line_5000_chars.txt` | `2500` | 0 |
| `tests/empty.txt` | Нет вывода | 0 |
| `tests/bad_token.txt` | Ошибка числа | 1 |
| `tests/too_long_number.txt` | Слишком длинное число | 1 |
| `tests/overflow.txt` | Ошибка суммы | 1 |
| `tests/missing.txt` | Ошибка открытия файла; такого файла нет | 1 |

Исходники и пример входа находятся в `src`, тестовые файлы — в `tests`,
трасса Process Monitor — в `extras`, копия отчёта с разбором трассы — в
`report`.
